# Issue 18 Importer Hardening Fix Evidence

Commit target: issue #18 importer BLOCK fixes after `.omo/evidence/18-independent-code-review.md`.

## Changed behavior

- Published refresh imports keep the active published locale pair, live `contentFile`, `snapshot.version`, `activeVersion`, and indexable SEO state intact. New source/translation hashes are recorded as a manifest `refreshCandidate` and mirrored in `snapshot.history`/`review.history` for review.
- Snapshot imports recompute `sha256(snapshot.html)` before using snapshot provenance or idempotence keys.
- Remote source and media fetches require HTTPS/public hosts, per-hop DNS checks, bounded redirects, and streamed byte limits. SVG media is accepted only when inert.
- Snapshot fixture media is limited to the programmatic fixture harness and the controlled fixture media root.
- Manifest read, ownership validation, merge, pair validation, staging, and commit now run under the importer lock.
- Manifest replacement rollback restores only backed-up targets and removes only replaced candidate targets.
- Import journals store staged file hashes and phase history. Recovery validates operation ids, staged relative paths, staged hashes, already-moved live files, and returns stable `recovery-conflict` when proof is missing.
- `tutorials:recover` exposes explicit recovery by operation id.
